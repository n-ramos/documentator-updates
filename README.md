# Documentator — mises à jour

Dépôt public contenant **uniquement** les artefacts de distribution de l’application Documentator : APK Android signés (dans les Releases) et le manifeste `android/latest.json` lu par l’application.

Aucun code source ni secret. Les APK sont publiés automatiquement par la CI ; Android refuse d’installer une mise à jour qui n’est pas signée avec la clé de l’application.
